# Chandni Sathish Kumar - AI/ML Software Engineer Portfolio

A professional resume portfolio website built with HTML, CSS, and JavaScript. This portfolio showcases experience, education, technical skills, and achievements in AI/ML engineering and scalable systems.

## Features

- **Terminal-style aesthetic** with a modern dark theme
- **Responsive design** that works on desktop, tablet, and mobile devices
- **Organized sections:**
  - Professional introduction
  - Educational background
  - Work experience at Amazon and Infibeam Avenues
  - Technical skills organized by categories
  - Publications and achievements
  - Contact information

## Technical Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Styling:** Custom CSS with CSS variables for easy theming
- **Icons:** Font Awesome 6.4.0
- **Fonts:** Roboto and Fira Code from Google Fonts

## Project Structure

```
portfolio/
├── index.html       # Main portfolio page
├── styles.css       # Styling and responsive design
├── script.js        # Interactive features
├── README.md        # This file
└── profile/         # Additional resources
```

## Getting Started

1. Clone or download the repository
2. Open `index.html` in a web browser
3. The portfolio will render with all content and styling

## Customization

To customize this portfolio for your own information:

1. **Update personal info in `index.html`:**
   - Change name and title in the hero section
   - Update contact information
   - Modify social media links
   - Update experience and education sections

2. **Update styling in `styles.css`:**
   - Modify color variables at the top of the file
   - Adjust fonts and sizes as needed

3. **Add interactivity in `script.js`:**
   - The script handles terminal cursor animation
   - Manages smooth scrolling
   - Processes publication links
